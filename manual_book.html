Dokumentasi Lampiran

Mengelola dan menyimpan segala arsip file tambahan, gambar nota, PDF, atau format dokumen lainnya untuk keperluan project management.

Menu Dokumentasi Lampiran digunakan untuk menyimpan file-file secara terpusat. Anda dapat mengupload banyak file sekaligus dalam satu dokumen untuk kemudahan akses dan manajemen arsip.

📤

Upload Multi-File

Klik tombol Tambah Dokumen dan Anda dapat memilih banyak file sekaligus (max 10MB per file) yang akan tergabung dalam 1 Judul Dokumen yang sama.

⬇️

Download & Detail

Klik Detail / Edit pada list dokumen untuk melihat rincian file yang pernah diupload. Anda bisa langsung mendownload masing-masing file pada halaman detail.

⏱️

Log Activity

Memantau riwayat aktivitas seluruh pengguna dalam platform secara real-time untuk audit dan transparansi.

Log Activity merekam setiap proses penting (Created, Updated, Deleted) yang dilakukan oleh user ke dalam sistem.

🔎

Pencarian & Filter History

Gunakan kolom pencarian atau filter berdasarkan aksi untuk melacak perubahan data secara spesifik. Anda juga bisa melihat IP Address dari user yang melakukan aksi.

🔄

Lihat Perubahan (Before/After)

Ketika tindakan "Updated" muncul, Anda dapat mengklik Lihat Perubahan Data untuk membandingkan JSON data sebelum dan sesudah perubahan secara akurat.
